Static Astro site, Markdown content collections, zero client-side JavaScript. The telemetry cards on the homepage are resolved at build time from the Strava API — nothing is fetched in the browser, so the refresh token never leaves the build.

Deployed on Vercel, rebuilt daily so the numbers stay current without a content change.
